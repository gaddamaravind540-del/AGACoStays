AGA CoStays Payment Service — copy/paste package

1. Create/open the Spring Boot project named payment-service.
2. Copy the ZIP contents preserving folders.
3. Create PostgreSQL database payment_db.
4. Set DB_USERNAME / DB_PASSWORD, JWT_SECRET and payment gateway settings.
5. In STS: Run As > Maven test, then Run As > Spring Boot App.

Port: 8088
Swagger: http://localhost:8088/swagger-ui.html
Health: http://localhost:8088/actuator/health

SOURCE ALIGNMENT
The source documents define Payment Service, payment_db, the payment workflow, the payment APIs, the package/file structure, and the rule that gateway/webhook state is authoritative. Exact enum members and several DTO fields are not fully enumerated in the source, so those implementation details are explicitly practical choices.

LOCAL GATEWAY MODE
payment.gateway.mock-enabled=true is suitable for local development. Production should disable mock mode and use the real gateway integration/credentials. Do not mark SUCCESS from a browser callback alone; verify the signed gateway result or webhook.
